[warm, clear teacher, friendly and patient] Today's question. Discuss the access privileges of class members within the same package and in different packages. [pause] Let's start from zero. [pause] A class member is a variable or a method inside a class. Access privilege just means: who is allowed to use it. Java gives you four levels. Think of a house. [pause] Private is your locked bedroom. Only you, the class itself, can enter. [pause] Default, where you write no keyword at all, is the whole house. Everyone in the same package can enter. [pause] Protected is the house, plus your children, the subclasses, even if they live in another package. [pause] Public is the street. Anybody, from any package, can walk in. [pause] So the question wants the access in two situations. The same package, and a different package. [pause] Let's fill the table. Same class: all four levels are allowed. [pause] Same package: private is blocked. The other three are allowed. [pause] Different package, but a subclass: only protected and public work. [pause] Different package, an unrelated class: only public works. [pause] So, the circle shrinks as you leave the package. [pause] So in your exam, write this. Private: only inside the same class. Default: the same package. Protected: the same package, plus subclasses in other packages. Public: everywhere. [pause] To remember it: Me. My package. My children. Everyone. [pause] Five marks. Secured.
