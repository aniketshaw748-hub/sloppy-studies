[warm, clear teacher, friendly and patient] Today's question. Explain how to create a user-defined package in Java, and import it into another program. [pause] Let's start from zero. Imagine a cupboard stuffed with loose papers. You can never find anything. So we sort them into labelled folders. [pause] A package is exactly that: a labelled folder for related classes. User-defined just means YOU make it. [pause] So the question wants two things. Create the package. Then import it elsewhere. [pause] Step one. Create it. The first line of the file says which folder the class belongs to. Write the word package, then the folder name, my pack, then a semicolon. [pause] So, the first line decides the folder. [pause] Step two. Save and compile. Save the file inside a real folder with the same name, my pack. Compile with javac, dash d, dot, and Java builds the folders for you. [pause] So, the folder name must match the package name. [pause] Step three. Import it. In the other program, write import, my pack, dot, A. That means: go to the folder my pack, and fetch class A. Then create an object and call its method. [pause] So, import fetches a class from the folder. [pause] One catch. The class must be public, or code outside the package cannot see it. [pause] So in your exam, write this. First line: package my pack. Save in folder my pack, compile with javac dash d dot. In the other program, import my pack dot A. Keep the class public. [pause] To remember it: Pack it. Place it. Pull it. Five marks. Secured.
