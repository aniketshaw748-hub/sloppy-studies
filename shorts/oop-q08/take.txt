[warm, clear teacher, friendly and patient] Today's question. Should a class be declared abstract if it does not define every method inherited from an interface? [pause] Let's start from zero. An interface is a contract: a list of methods that a class promises to write. Think of a builder who signs to build a house with five rooms. [pause] If the builder finishes only three rooms, the house is incomplete. [pause] So the question wants a yes or no, and why. [pause] The answer is yes. An unfinished class cannot make objects, so Java makes you mark it abstract. An abstract class may leave methods undefined, but gets no objects. A child class must finish the job. [pause] So in your exam, write this. Yes. A class that does not implement all the interface methods must be declared abstract. It cannot be instantiated, and a subclass must complete the missing methods. [pause] Remember: unfinished means abstract. Two marks. Secured.
