[warm, clear teacher, friendly and patient] Today's question. Which access specifier allows a class member to be accessed only within its own class? [pause] Let's start from zero. A class has members: variables and methods. An access specifier is a keyword that decides WHO may use a member. Think of your house. The living room is open to guests. But your diary stays locked in your own room. [pause] So the question wants one word: the lock that opens only from inside. [pause] Java has four levels. Public: anyone can use it. Protected: the same package, and child classes. Default: the same package only. And private: only the class itself. [pause] So: private is the tightest lock. No other class can touch a private member, not even a child class. [pause] So in your exam, write this. The private access specifier. A private member is accessible only within its own class. [pause] Remember: private is a diary lock. Two marks. Secured.
