[warm, clear teacher, friendly and patient] Today's question. Write a program showing one interface extending another interface. [pause] Let's start from zero. An interface is a list of promises. Think of a driving licence. A learner licence lists the basic skills. A full licence lists everything from the learner licence, plus some more. [pause] One interface can build on another in the same way, and the word it uses is EXTENDS. [pause] So the question wants three things. A first interface. A second one that extends it. And a class that uses the second. [pause] Step one. The base interface. Animal promises one method, eat. [pause] Step two. The child interface. Pet extends Animal, and adds one new method, play. So Pet holds two promises: eat, inherited, and its own, play. Notice, extends, not implements. Interfaces extend interfaces. [pause] So, Pet carries every promise of Animal, plus its own. [pause] Step three. The class. Dog implements Pet. Dog must write BOTH methods, eat and play, and keep them public. In main, create a Dog, and call eat, then play. The output is: Dog eats. Dog plays. [pause] So, the class must keep every promise in the whole chain. [pause] So in your exam, write this. Interface Animal with eat. Interface Pet extends Animal, with play. Class Dog implements Pet, with both methods public. Then main creates a Dog and calls both. [pause] To remember it: interface extends interface. Class implements interface. Five marks. Secured.
