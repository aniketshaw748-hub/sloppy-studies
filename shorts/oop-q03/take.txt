[warm, clear teacher, friendly and patient] Today's question. Can an interface contain a constructor? Justify. [pause] Let's start from zero. A constructor is a special method that runs once, when an object is created, to fill in its fields. Think of a car factory's assembly line. [pause] An interface is different. It is only a contract: a list of method names that a class promises to provide. Think of a job advert: it lists skills, but it is not a person. [pause] So the question wants a yes or no, and the reason. [pause] The answer is no. Reason one: you can never create an object of an interface, so there is nothing for a constructor to build. Reason two: an interface has no instance fields to set up, only constants. So: nothing to build, nothing to initialise. [pause] So in your exam, write this. No. An interface cannot be instantiated, and it has no instance variables to initialise. Remember: a contract needs no assembly line. Two marks. Secured.
