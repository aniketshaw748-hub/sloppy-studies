[pause] A thread is a separate path of work inside a program. Even a simple program has one: the main thread, which runs main. And when you start more threads, many of them may run the very same code. [pause] Think of a hospital where all the nurses follow the same instructions. Each nurse wears a name badge. Looking at your own badge answers one question: who am I? [pause] So the question wants two things. The purpose of currentThread. And a small program. [pause] The purpose. Thread dot currentThread is a static method of the Thread class. It hands you the thread that is running THAT line, right now. It is the thread looking at its own badge. [pause] With it you can read or change the thread's name or priority. It matters most when many threads share the same code, because it tells you which one is running. [pause] So, currentThread returns the thread that is executing this line. [pause] Now the program. In main, we call currentThread and print its name. It prints: main. [pause] Then we start a Worker thread. Inside its run method, we call currentThread again and print the name. This time it prints: Thread dash zero. [pause] So, same code, different badge. [pause] So in your exam, write this. currentThread is a static method of Thread. It returns a reference to the thread now executing. Use it to get or set the name and priority.
