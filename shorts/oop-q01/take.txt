[warm, clear teacher, friendly and patient] Today's question. What is the purpose of the package keyword in Java? [pause] Let's start from zero. A Java program is made of many classes. Think of a school office. Put every student file in one giant drawer, and nothing can be found. [pause] The fix is folders. A package is a named folder for classes. [pause] So the question wants two things. Grouping, and no clashes. [pause] First, it groups. The line package shop, at the top of a file, puts that class in the shop folder. So: related classes live together. [pause] Second, it avoids clashes. Shop dot Student and school dot Student can both exist, because the folder name is part of the full name. So: same class name, different package, no clash. [pause] So in your exam, write this. A package groups related classes and interfaces into one namespace. It prevents name conflicts, and it must be the first statement in the file. [pause] Remember: package equals folder. Two marks. Secured.
